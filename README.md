# Docker Web Application with Jenkins CI/CD 🚀

## 📌 Project Overview

This project demonstrates how to build, containerize, test, publish, and deploy a simple web application using Docker and Jenkins.

The project uses GitHub for source code management, Docker for containerization, Docker Hub as the image registry, and Jenkins to automate the CI/CD pipeline.

## 🏗️ Architecture

Developer
   ↓
GitHub
   ↓
Jenkins
   ↓
Docker Build
   ↓
Docker Image
   ↓

   ↓
Docker Pull
   ↓
Docker Container
   ↓
Web Application
